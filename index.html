7. Algorithm Explanation (Neural Network)

What you are building
Model: 1-hidden-layer Neural Network (Dense → Activation → Dense)
Goal: เรียนรู้พารามิเตอร์ (W,b) ให้ทำนายได้แม่นยำจากข้อมูล
Training: ทำซ้ำหลาย epoch โดยใช้ Gradient Descent เพื่อลด Loss
Forward Pass
Hidden: z1 = XW1 + b1 → a1 = activation(z1)
Output: z2 = a1W2 + b2 → ŷ = output(z2)
Binary มักใช้ sigmoid ที่ output, Regression ใช้ linear
Loss Function
Binary: Binary Cross-Entropy วัดความผิดพลาดของความน่าจะเป็น
Regression: MSE วัดค่าเฉลี่ยกำลังสองของ error (ŷ − y)
Backpropagation (concept)
คำนวณ gradient ของ loss ต่อพารามิเตอร์แต่ละตัวด้วย chain rule
dL/dW2, dL/db2, dL/dW1, dL/db1 แล้วส่งกลับผ่าน activation
Parameter Update
Gradient Descent: W := W − lr · ∂L/∂W และ b := b − lr · ∂L/∂b
lr (learning rate) คุม “ก้าว” ในการปรับพารามิเตอร์
Show tips for students
  • เริ่มจาก hidden น้อยๆ (เช่น 4–16) แล้วค่อยปรับ
  • ถ้า loss ไม่ลง: ลด lr หรือเพิ่ม epochs
  • ถ้า overfit: ลด hidden/epochs หรือเพิ่ม regularization (ทำใน JS เพิ่มได้)
